# Коворкинг «Точка»

Веб-приложение для бронирования рабочих мест и переговорных. Серверная часть построена на Django, клиентская — на HTML, CSS и JavaScript без фронтенд-фреймворков.

## Запуск локально

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Панель управления Django доступна по адресу `/admin/`. Письма в режиме разработки выводятся в консоль.

Демо-команда создаёт места, тарифы, услуги, резидентов и не менее 30 броней. У демонстрационных резидентов пароли не заданы — создайте пользователя через регистрацию или панель Django. Для email-напоминаний об окончании брони запускайте `python manage.py send_booking_reminders` по расписанию (например, раз в 15 минут).

Настройки можно переопределить переменными окружения; шаблон находится в `.env.example` и задаёт `DJANGO_DEBUG=False` для сдаваемой версии. При локальном запуске `DJANGO_DEBUG` по умолчанию включён, чтобы Django обслуживал статические файлы. Для демонстрации оплаты используется внутренняя имитация подтверждения, платёжный провайдер не подключён.
